# 05_Bewertung

Phase 5. Was der Prototyp leistet, was nicht, und was daraus folgt.

## Was hierher gehört

| Datei | Inhalt |
|---|---|
| `bewertung.md` | Was der Prototyp leistet und was nicht, belegt mit den Testfällen aus `04_Prototyp` |
| `grenzen.md` | Daten, Schnittstellen, Rechte, Modellqualität, Datenschutz: Welche Voraussetzungen müssten erfüllt sein, damit der Ablauf real eingesetzt werden könnte? |
| `empfehlung.md` | Empfehlung an den Verwaltungsbereich: weiterverfolgen, anpassen oder nicht weiterverfolgen, mit Begründung |
| `ki-nutzung.md` | Offenlegung, wofür KI-Werkzeuge in der Projektarbeit genutzt wurden |
| `praesentation.pdf` | Folien der Abschlusspräsentation |

## Prüfen

- Die Empfehlung folgt aus den Testfällen, nicht aus dem Eindruck einer Demo.
- Eine begründete Empfehlung gegen den Einsatz ist ein vollwertiges Ergebnis.
- Die Präsentation sagt zu Beginn, dass Daten und Schnittstellen erfunden sind.
